# 架构设计

## 设计范围

拾影采用基于文件目录的照片管理模型。应用不建立独立的照片数据库，也不将照片迁入专有图库；JPG / RAW 配对关系由扫描结果推导，用户配置、标记及文件操作记录通过 JSON 持久化。

系统分为界面、应用状态、领域服务和文件存储四个层次。界面负责呈现和输入，`LibraryStore` 协调相册与窗口，领域服务负责扫描、导入、评测和编辑，存储模块负责文件身份验证与持久化。

## 状态与存储归属

| 数据 | 生命周期与存储位置 |
| --- | --- |
| 相册配置、目录路径、删除恢复批次 | 默认位于用户 Application Support 中的 `PhotoHarbor/state.json`。 |
| 导入操作清单 | 状态目录中的 `import-UUID.json`，用于记录已完成文件。 |
| 颜色和待删除标记 | 照片同级 `.photoharbor-marks/`；`state.rejected` 仅作为兼容缓存。 |
| 最初 JPG 及编辑校验记录 | JPG 同级 `.photoharbor-originals/`。 |
| 用户 LUT / XMP 库 | 状态目录中的 `LUTs/` 和 `Filters/`。 |
| 评测、对比选择、未保存编辑及撤销栈 | 进程或编辑会话内存，退出后不持久化。 |

`PHOTOHARBOR_STATE_PATH` 可覆盖默认配置路径，用于隔离开发与测试。标记和原始备份的详细协议分别见 [MARKS](MARKS.md) 与 [EDITOR](EDITOR.md)。

## 相册打开与分类导入

### 打开已有相册

相册可配置 JPG 和 RAW 两个根目录，至少提供一个。打开操作只扫描和配对，不复制、分类或移动文件。应用支持多个独立相册，拒绝重叠根目录，避免同一文件被重复管理。关闭相册不改动照片，但会清理对应会话与删除撤销记录。

### 分类导入

导入分为计划和执行两个阶段。计划阶段确定拍摄日期、地点及目标路径，用户确认后执行校验复制。

```text
JPG 根目录 / YYYYMMDD_地点 / 原文件名
RAW 根目录 / YYYYMMDD_地点 / 原文件名
```

地点优先级为手动输入、IPTC 信息、GPS 反查，最终回退为「未知」。缺失拍摄时间时提示使用文件修改时间；配对文件保持一致的分类日期。两个目标位置相同时，在该位置下分别创建 `JPG/` 与 `RAW/` 子目录。

## 文件操作约束

以下约束是修改扫描、导入、删除或恢复逻辑时必须保持的行为：

1. **配对唯一性**：优先使用相对相册路径与文件主名配对，忽略大小写；备用匹配仅在两侧主名均唯一时使用。存在歧义的照片不可执行成对删除。
2. **身份核验**：扫描跳过符号链接；写入或移动前重新检查根目录、文件身份及预期属性。离线目录不解释为空相册。
3. **导入不覆盖**：来源文件保留，目标文件不覆盖；流式 SHA-256 校验通过后发布。中断保留完成清单，重试不自动覆盖或续传。
4. **标记不误继承**：待删除状态绑定经过验证的文件内容，同名替换文件不继承旧删除意图。
5. **删除可恢复**：删除经确认后进入系统废纸篓，按相册和操作批次记录。恢复不覆盖已有文件，单项失败不阻止其他项目继续。
6. **恢复记录有界**：相册关闭、失联或废纸篓文件不存在时，相关恢复记录会清理或失效。

文件移动与记录更新不具跨卷或断电事务保证。JPG 编辑是明确的覆盖例外，必须遵守首次备份、摘要验证与发布协议。

筛选导出是独立复制流程，不修改导入的不覆盖规则。导出面板快照当前可见照片，来源属性变化时拒绝复制；同名文件默认保留两者，替换必须逐项明确选择并复核目标身份及摘要。禁止替换当前管理的任一来源路径或其硬链接；符号链接目标不允许替换。临时副本经 SHA-256 校验后发布，保留两者的发布不覆盖新出现的目标。替换使用系统原子替换接口，检查与发布之间不提供对外部并发写入的事务隔离保证。每个文件独立处理，部分失败或停止不回滚已完成项；数字后缀也按文件分配，可能改变 JPG / RAW 的同名关系。

## 窗口、视野与评测

大图与对比分别复用一个独立 `NSWindow`。从浏览页打开其他照片会更新并激活已有窗口，包括全屏窗口。每个画布独立维护缩放比例与偏移；当前画布的「适应窗口」不改变其他照片视野，「全部适应」通过共享 token 通知各画布。

工具栏和评测面板分别维护自动隐藏与固定状态。固定评测面板占用独立侧栏，悬浮评测面板覆盖照片边缘并避开标题栏。对比选择最多四张；清空选择不修改文件或标记。

审美参考来自 Vision，原始值线性映射至 0–100；特征距离越小表示越相似，但不是相似概率。细节能量、近黑 / 近白比例和直方图基于降采样预览计算，不等同于对焦准确率。大图预览长边最高 8000 像素，不保证原片逐像素显示。

## 编辑并发与一致性

编辑状态由主线程模型持有，Core Image 处理由后台 actor 隔离。预览使用缩小图，单个渲染循环合并连续输入，发布几何一致的编辑前后预览，并最终收敛至最新参数。保存重新读取全尺寸 JPG。

`ImageGeometryPlan` 统一保存、预览、参考图与画笔反算的变换。编辑前参考图、滤镜缩略图和 LUT 解码结果按受限策略缓存。系统补充参数控件使用稳定标识访问配方；撤销或还原移除参数后，旧绑定读取中性值，避免失效下标访问。

保存或还原后重新扫描照片、恢复路径选择并失效相关缩略图及评测缓存。颜色标记刷新到新文件版本，待删除状态清除；旧对比选择不自动继承。
