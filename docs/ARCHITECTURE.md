# 结构与行为约定

## 模块

| 模块 | 职责 |
| --- | --- |
| `PhotoHarborApp`、`PhotoHarborDelegate` | 入口、应用菜单、原生应用生命周期 |
| `Models` | Photo、Roots、OpenAlbum、SavedState、导入与删除记录、元数据 |
| `LibraryService` | 扫描、配对、地点解析、导入计划、校验复制、删除前核验、恢复 |
| `LibraryStore` | 主线程可观察状态、会话、后台任务、状态保存及窗口复用 |
| `Views` | 三栏浏览、打开相册、导入、检查器、单图及删除历史 UI |
| `PhotoViewer`、`ViewerGeometry` | 原生画布、缩放平移、导航预览与几何计算 |
| `ViewerChrome`、`MainToolbar` | 浮动控件、边缘悬停、图钉、原生右侧操作组 |
| `ComparisonView`、`ComparisonSelectionPopover` | 对比画布、全组指标表、已选缩略图、单张移出与清空 |
| `PhotoAssessment`、`Thumbnail` | 本机模型评测、图像解码、有限大小缓存 |

不使用数据库。配对由扫描结果推导；配置、相册、待删除标记和恢复批次保存为 JSON。图片评测和对比选择当前只存于内存。

## 打开相册与导入是两种操作

打开已有 JPG / RAW 目录仅原位配对，不分类或复制。至少提供一种格式；支持多个独立相册。拒绝重叠根目录，避免同一文件被多次管理。关闭相册只移出列表，不动照片。

导入先生成预览计划，确认后复制到 `JPG根目录/YYYYMMDD_地点/原文件名` 和 `RAW根目录/YYYYMMDD_地点/原文件名`。两边默认在来源同级；选择相同目标位置时生成 JPG / RAW 子目录。地点优先手填，其次 IPTC，再尝试 GPS 在线反查，失败用「未知」。配对文件保持相同分类日期；缺失拍摄时间时提示使用文件修改时间。

## 配对与文件操作不变量

1. 优先按相对相册路径 + 文件主名（忽略大小写）配对；其余仅在两侧主名都唯一时配对。歧义文件不可删除。
2. 扫描跳过符号链接；离线目录不视为空库，操作前重新核对根目录和文件身份。
3. 导入保留源文件，不覆盖目标；流式 SHA-256 校验后发布文件。中断保留已完成清单，重试不自动覆盖或续传。
4. 待删除标记绑定路径、文件身份、大小和修改时间，同名新文件不继承旧标记。
5. 删除经确认进入系统废纸篓；每批记录归属相册。恢复遇到缺失 / 冲突会继续处理其他文件，不覆盖现有文件。
6. 关闭或失联相册清理其撤销记录；废纸篓文件消失时失效。移动文件与保存记录不具跨硬盘 / 断电事务性，极端情况下仍需从系统废纸篓找回。

## 窗口与评测

大图和对比各复用一个独立 NSWindow，全屏时从浏览页打开新图片会更新并激活原窗口。画布各自维护缩放 / 偏移；右键适应窗口仅复位当前画布。「全部适应」通过共享 token 通知所有画布。

工具条和评测浮层有独立的隐藏 / 固定状态；固定评测占用侧栏宽度，悬浮评测避开标题栏。对比最多四张；清空或移出只改变选择，不改照片或删除标记。

Vision 提供审美分与特征距离；审美原始值线性映射到 0–100，特征距离越小越相似，不是相似概率。细节能量、近黑 / 近白比例和直方图由降采样预览计算，不能直接解释为对焦准确率。大图使用最高 8000px 长边预览，不保证原片逐像素显示。
