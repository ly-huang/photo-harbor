# 编辑系统

## 编辑范围与会话模型

编辑器支持 JPG / JPEG，采用「调整、滤镜、裁剪」三个工作区。顶部工具栏提供文件状态、返回、保存及界面控制；底部提供视野适应、工作区切换和编辑前后对比，右侧面板显示当前工作区的工具。

调整参数和撤销 / 重做栈仅在编辑会话内保存。保存会重新编码并覆盖 JPG，首次保存前建立原始文件备份；RAW 文件不修改。RAW-only 照片暂不支持编辑。保存后可通过「还原最初 JPG」恢复首次备份的原始字节。

## 调整工具

调整面板按功能分组，各组支持展开、停用和复原。停用保留参数，重新启用后恢复效果；组内自动按钮使用系统建议或应用预设建议。系统可用的补充参数归入对应分类，并在该照片的编辑会话内常驻。

| 分类 | 主要功能 |
| --- | --- |
| 光效 | 综合光效、鲜明度、曝光、高光、阴影、亮度、对比度、黑点及局部对比半径。 |
| 颜色 | 综合颜色、饱和度、自然饱和度、色偏及可用的系统色彩参数。 |
| 黑白 | 强度、中性、色调与颗粒。 |
| 修图 / 消除红眼 | 附近纹理柔和修补、局部红色抑制。 |
| 白平衡 | 中性灰色或肤色取样、色温和色调。 |
| 曲线 | RGB 整体及独立 R / G / B 通道曲线。 |
| 色阶 | 整体及各通道的输入黑点、白点、伽马和输出范围。 |
| 清晰度 / 噪点消除 / 锐化 | 局部细节、降噪及锐化参数。 |
| 可选颜色 | 六个默认色组与独立照片取样颜色的色调、饱和度、亮度及范围。 |
| 晕影 | 强度、半径与柔和度。 |
| 人物美化 | 人脸区域柔肤、提亮及系统提供的人脸色彩平衡参数。 |

局部对比半径控制高光 / 阴影处理的空间作用范围，不是独立效果强度。高光和阴影保持默认值时，仅改变半径通常没有可见效果。

### 一键美化

自动增强调用 Core Image 的 `CIImage.autoAdjustmentFilters(options:)`，启用增强并关闭自动红眼、裁剪和水平校正。返回的滤镜顺序和参数被保留，基础参数映射到常规控件，其余受支持参数显示在所属分类中。标量、向量、颜色和布尔参数均可表达；不支持的参数类型会报错，不静默丢弃。

编辑器在本机用 Apple Vision 检测方向已校正的 JPG 预览。macOS 15 及以上采用系统默认版本的 Swift 请求，macOS 14 使用兼容的 Vision 请求。检测失败时仍可编辑其他项目。检测到人脸时，一键美化还启用 25% 强度的局部柔肤。该效果由人脸区域蒙版、降噪和轻微提亮组合实现。自动增强与柔肤构成一次撤销操作。

所有处理均在本机执行。编辑器使用公开 API 实现功能，不调用 Apple 照片的私有编辑组件，也不保证与其自动增强结果相同。局部修饰不是生成式修复，人物美化不提供五官重塑。

### 曲线与直方图

每条曲线支持 2–32 个有序控制点。单击图面添加点，拖动调整，右键或减号移除当前点，也可通过数值控件精调。取样工具作用于当前通道：

| 工具 | 操作含义 |
| --- | --- |
| 黑点 | 将照片中所选色调的输出设为 0%。 |
| 中间调 | 将所选色调的输出设为 50%。 |
| 白点 | 将所选色调的输出设为 100%。 |
| 取点 | 在当前曲线上为照片中的色调添加控制点，保留该位置的当前输出。 |

系统增强的五点整体曲线沿用原生 `CIToneCurve`；非五点整体曲线及独立通道曲线通过保形插值生成查找数据。曲线图用于交互参考，不承诺复现 Apple 私有曲线算法。

曲线和色阶使用当前预览的 256 档亮度 / R / G / B 直方图。显示高度采用平方根缩放以提高低频区域可读性，不改变统计分布或照片内容。

### 照片取色

曲线和可选颜色吸管从明确转换为 sRGB 的原始预览读取像素，并通过统一几何反算定位源图。旋转、翻转、透视及裁剪后仍使用对应的源像素位置。

可选颜色中的照片取样使用独立的第七项，保留实际 sRGB 色值和目标色相，不覆盖六个默认色组。再次取样会更新该项的目标颜色，并保留其调整参数。参数条以渐变显示色调、饱和度、亮度与范围的调整方向。

## 滤镜与 LUT

### 内置风格

内置选择包含原始状态、鲜明、鲜暖色、鲜冷色、反差色、反差暖色、反差冷色、单色、银色调和黑白。每项使用当前照片生成缩略预览，可调节应用强度。

鲜明和反差系列使用公开 Core Image 效果近似实现；黑白系列使用系统公开滤镜。这些风格不保证与 Apple 照片逐像素一致。

### 用户资产库

滤镜预设描述一组调整参数，LUT 描述 RGB 颜色映射。两类资产分别管理，可独立选择并叠加。主页与编辑器共用管理窗口，支持多文件导入、命名、搜索、重命名和移除。

编辑器通过「滤镜」与「LUT」按钮打开各自的选择气泡，提供搜索、当前照片预览、不套用和分类管理入口。管理窗口没有当前图片时只显示资产信息。

| 格式 | 支持范围 | 文件限制 |
| --- | --- | --- |
| `.cube` | UTF-8 三维 LUT，网格维度 2–64，支持 `DOMAIN_MIN` / `DOMAIN_MAX`。拒绝 1D LUT、无效数值及不匹配的数据行数。 | 最大 32 MB。 |
| `.xmp` | Lightroom / Camera Raw 参数预设的支持子集，包括基础光色、曲线、六色 HSL、黑白、锐化、降噪和晕影等。 | 最大 2 MB；限制 XML 深度和元素数。 |

XMP 禁止 DTD 和外部实体解析，不读取引用的外部文件或网络资源。Adobe 配置文件、局部蒙版、镜头校正和其他未映射参数在兼容性说明中列出；没有可用调整参数的预设拒绝导入。色温、曲线等参数可能近似转换，效果与 Lightroom 存在差异。

资产复制到状态目录中的 `LUTs/` 或 `Filters/`，原文件保留。内容摘要用于身份、去重和套用前校验。名称为去除首尾空白后的 1–80 个字符，拒绝控制字符、斜杠、冒号和同类重名；相同内容复用已有条目及名称。

批量导入没有固定文件数量上限，逐文件后台处理并显示进度。失败项保留供更名或重试，成功项正常入库。移除只影响库内资产，不回溯修改已保存的照片。

## 几何与前后对比

裁剪工作区提供左右 90° 旋转、±45° 校正、水平 / 垂直翻转、水平 / 垂直透视、常用或自定义宽高比及横竖方向切换。裁剪框支持四角、四边调整及框内移动。校正与透视会裁去空白边缘。

构图推荐使用本机 Vision 显著区域（macOS 15 及以上使用 Swift 版请求）生成启发式边界，无有效结果时回退保守框；推荐结果不代表审美最优。

点击对比按钮切换完整编辑前 / 编辑后；按住 ⌥ 并移动鼠标进入临时分割，松开或移出画布恢复。两侧采用相同几何和视野，使差异集中在图像调整效果。空间不足时隐藏边缘标签，防止文字重叠。

## 渲染与缓存

预览以缩小图在后台 actor 中处理，连续输入合并到单个渲染循环。输出以完整的编辑前后预览对发布，停止输入后收敛到最终参数。编辑前几何、滤镜预览和 LUT 解码结果使用有限缓存；保存始终重新读取全尺寸源文件。

系统补充参数控件以稳定的滤镜 / 参数标识访问模型，不保留可变数组下标。撤销或还原后，旧绑定读取中性值；控件模板保留，组开关和复原统一管理常规与补充参数。

## 覆盖保存协议

1. 打开编辑时从同一份 JPG 数据解码并计算 SHA-256，记录文件版本。保存时同样复用解码所用的数据核验来源。
2. 首次保存前，在 JPG 同级 `.photoharbor-originals/` 建立字节一致的原始备份与校验记录。
3. 从全尺寸源文件渲染高质量 sRGB JPEG，保留拍摄 EXIF / IPTC / GPS 并规范方向。
4. 生成同目录临时文件，验证可解码性与摘要，持久化待发布摘要后再次核对源文件。
5. 通过原子替换发布 JPG。能确认发布后仍是已核验的临时文件时复用其摘要，身份无法确认时重新核验内容，再更新已保存摘要。待发布记录可识别发布后记录更新中断的情况。

后续保存不覆盖最初备份；还原后备份继续保留。外部改动、损坏备份或符号链接会阻止保存 / 还原。文件重命名后不会自动沿用原名备份；移动相册时应保留同级隐藏目录。

还原最初 JPG 时只读取一次备份，用同一份数据核验内容摘要、验证 JPG 并生成还原文件。

普通成对删除不会清除原始备份。共享或清理相册时，应将隐藏目录视为照片数据的一部分。每次保存都会重新编码 JPEG；最初备份还原则为字节级恢复。

## 验证边界

自动测试使用合成图像，覆盖参数映射、像素变化、几何一致性、全尺寸保存、元数据、备份与失败恢复。真实人像柔肤的视觉质量、不同相机 RAW 解码及旧系统兼容性仍需独立实机验收。数据安全约束见[架构设计](ARCHITECTURE.md)，本机数据范围见[隐私文档](PRIVACY.md)。
