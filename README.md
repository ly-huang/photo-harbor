# 拾影 · Photo Harbor

拾影是一款原生 macOS 相机照片管理应用，面向 JPG 与 RAW 双格式拍摄工作流，提供目录配对、分类导入、照片筛选、并排对比和 JPG 编辑。应用使用 SwiftUI、AppKit、Core Image 与 Vision，无第三方运行时依赖。

## 核心能力

| 工作流 | 功能 |
| --- | --- |
| 相册管理 | 原位打开 JPG / RAW 目录，同时管理多个相册，支持仅含一种格式的相册。 |
| 分类导入 | 按拍摄日期与地点生成 `YYYYMMDD_地点` 目录，分别复制 JPG 与 RAW，并校验文件内容。 |
| 浏览与筛选 | 连续缩放、平移、全屏预览、颜色标记、待删除标记和文件信息查看。 |
| 照片对比 | 同时对比 2–4 张照片，独立调整视野，查看本机评测和图像相似距离。 |
| JPG 编辑 | 自动增强、分组调整、RGB 曲线、局部修饰、滤镜、LUT、旋转、透视与裁剪。 |
| 删除与恢复 | 将配对文件一起移入系统废纸篓，按相册和操作批次恢复。 |

照片保存在用户选择的目录中。打开相册不复制或重排文件；分类导入保留来源文件；编辑保存会覆盖 JPG，并在首次保存前建立原始备份。RAW 文件不参与编辑覆盖。

## 系统与构建要求

- **运行系统**：macOS 14 或更高版本；审美评分需要 macOS 15+，系统玻璃效果需要 macOS 26+。
- **构建工具**：Xcode 26+，或包含 macOS 26+ SDK 的 Command Line Tools。源码以 Swift 5 语言模式编译；使用 Swift Package Manager 时还需支持 Swift 6 manifest 的工具链。
- **架构**：构建脚本生成当前 Mac 架构的应用，暂不生成 Universal Binary。旧版 macOS 和 Intel Mac 尚未完成全面实机验证。
- **签名**：本地构建采用临时签名，不需要开发者证书。Developer ID 签名、公证和自动更新尚未提供。

## 下载安装

无需编译的用户可前往 [GitHub Releases](https://github.com/ly-huang/photo-harbor/releases/latest) 下载 Apple Silicon DMG，打开后将「拾影.app」拖入「Applications」。安装包附带 SHA-256 校验文件；当前版本未经 Apple 公证，首次打开可能受到系统安全检查限制。完整兼容性、签名状态和发布流程见[构建分发指南](docs/DISTRIBUTION.md)。

## 快速开始

在仓库根目录执行：

```sh
zsh scripts/check.sh
zsh scripts/build-app.sh --release
open "dist.noindex/拾影.app"
```

开发时可使用 `zsh scripts/build-app.sh` 生成增量 debug 构建。构建输出和缓存均为本地产物，不进入仓库。完整工具链说明见[开发指南](docs/DEVELOPMENT.md)。

如需安装，先退出正在运行的拾影，再执行：

```sh
zsh scripts/install-app.sh
open "/Applications/拾影.app"
```

安装脚本校验目标应用标识与签名，默认安装至系统应用程序目录，并迁移用户应用程序目录中的旧副本。脚本不自动使用 `sudo`；目标目录需具备写入权限。构建和测试无需安装应用。

## 使用流程

### 管理已有照片

启动时按相册扫描目录、配对 JPG / RAW 并读取照片标记。已加载的相册可先浏览，状态栏显示扫描进度。扫描期间也可准备导入预览或管理滤镜和 LUT，正式复制等扫描结束后再执行。新增相册时只扫描该相册。需要同步其他相册的外部改动时，可手动重新扫描。

选择「打开相册」，指定 JPG 或 RAW 目录，至少填写一项。拾影扫描目录并推导配对关系，不移动照片。右键可关闭单个相册，悬停在关闭项上会显示说明。点击「拍摄相册」标题旁的关闭按钮并确认，可一次关闭所有相册。关闭会清除相关的废纸篓撤销记录，磁盘照片及随目录保存的标记会保留。

### 分类导入一次拍摄

选择一个或多个来源目录、可选地点以及整批共用的两种格式目标位置，预览导入计划后确认执行。目录命名使用 `YYYYMMDD_地点`；地点缺省时依次读取照片元数据并尝试 GPS 反查，无法确定时使用「未知」。目标默认位于列表中第一个来源目录同级；两种格式指定同一目标时，自动使用其中的 `JPG/` 和 `RAW/` 子目录。

多来源按各目录独立配对，来源目录不能重复或互相包含。预览会一次列出各来源中无法配对的同名组和无法读取的目录，标明文件路径及格式数量。同批照片分到同一相册且主文件名冲突时，后续照片会自动添加数字后缀，配对文件共用后缀。导入预览会标出磁盘上的同名目标，可统一选择跳过、保留两者或替换已有文件。默认跳过。跳过或保留两者时，配对的 JPG 与 RAW 一起处理。替换需要明确选择，执行前会重新核验目标。

导入完成后，会选中本批次按名称排序的第一个相册并定位侧栏。状态栏显示相册数量，悬停可查看完整名称。生成预览时可点「取消预览」或按 Esc，保留已填写的设置。导入预览最多同时扫描三个来源目录，以有限并发读取分类所需的元数据，最终地点确定后按目标目录批量检查重名。地点留空时，可关闭「在线根据 GPS 补全地点」，照片内已有的地点仍可使用。选择「替换并导入」后会沿用预览计划并核验同名目标文件。复制时同步计算来源摘要，随后读取目标核验。最多并行准备两份文件，按计划顺序发布，完成列表随导入任务结束释放。导入结束后仅刷新受影响的相册，其他相册可手动刷新。

### 筛选与编辑

通过右键菜单设置六种颜色标记、加入对比或标记待删除。主页可按颜色筛选；待删除照片仍需确认后才移入废纸篓。大图中的「编辑」进入 JPG 编辑器，保存覆盖当前 JPG，「还原最初 JPG」使用首次备份恢复原始字节。

颜色筛选启用后，可用「导出筛选照片」复制当前可见结果（同时遵循相册、分类和搜索条件），不受对比选择影响。选择目标目录，默认分别写入 `JPG/`、`RAW/`，也可混合写入目标目录；缺失目录自动创建。冲突时逐文件选择保留两者（数字后缀）、替换或跳过，替换不可撤销，不能替换相册来源文件。仅导出照片内容，不复制隐藏标记或编辑备份。完成后显示成功、跳过及失败数量；停止保留已完成文件。

评测分数和相似距离用于辅助筛片，不代表客观审美结论或相似概率。内置风格及 XMP 参数映射使用公开图像处理接口，效果不保证与 Apple 照片或 Lightroom 完全一致。

主页缩略图缓存预算为 512 MiB。大图按当前照片位置向前后预加载，以 1024 MiB 解码内存预算维护滑动缓存，不限制张数；照片越大，可缓存张数越少。当前照片和后台预加载独立解码，已缓存的大图可以直接取用。关闭大图释放其缓存，App 总内存还包含画布、编辑器和临时解码开销。

系统内存压力升高时，大图缓存逐级减小预算；严重压力下清空缓存、暂停预加载，继续提供当前照片浏览。压力恢复后从低预算逐步恢复。

## 常用操作

快捷键受当前窗口和编辑状态影响。

| 操作 | 入口或按键 |
| --- | --- |
| 打开相册 / 导入照片 | ⌘O / ⌘I |
| 查看大图 | 双击照片或 Return |
| 标记 / 取消待删除 | 浏览及大图中按 ⌫ |
| 切换照片 | ← / → |
| 适应窗口 | F、⌘0 或照片右键菜单 |
| 平移图像 | 左键拖动，或按住空格移动鼠标 |
| 固定 / 自动隐藏工具栏 | H |
| 选择对比照片 | 右键加入对比，最多四张；「已选照片」管理选择 |
| 编辑前后对比 | 点击编辑页底部按钮；按住 ⌥ 并移动鼠标临时分割 |
| 编辑撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 撤销删除 | 浏览窗口中按 ⌘Z，或从删除历史选择批次 |
